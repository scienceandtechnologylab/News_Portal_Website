# 📰 Dynamic News Portal Website

A robust, fully functional, and secure dynamic News Portal Web Application built with **PHP** and **MySQL**. This platform features a responsive user frontend for readers and a feature-rich admin dashboard for complete content management.

---

## ✨ Features

### 🌐 User Frontend
- **Dynamic Homepage:** Modern news layout displaying breaking news, featured stories, and latest updates.
- **Categorized Content:** Easy navigation across different news categories (e.g., Politics, Tech, Sports, Entertainment).
- **Article View:** Full story reading interface with clean typography and image support.
- **Interactive Messaging:** Visitors can reach out to administrators via contact forms.
- **Subscriber System:** Users can subscribe/unsubscribe to stay updated with latest notifications.

### 🛡️ Admin Dashboard
- **Content Management System (CMS):** Add, edit, update, and delete news articles (`manage_news.php`, `add_news.php`, `edit_news.php`).
- **Category Management:** Manage dynamic news categories on the fly.
- **User & Access Control:** Admin user creation and role/status tracking.
- **System Diagnostics & Logs:** View application activity logs (`logs.php`) and server configurations (`phpinfo.php`).
- **Message Center:** Review user inquiries directly from the admin interface (`messages.php`).

---

## 🛠️ Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap / Modern CSS Utilities
- **Server:** Apache (WAMP / XAMPP / Lamp Environment)
